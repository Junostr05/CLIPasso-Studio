## Welche Datei brauche ich? · Which file do I need?

| Du hast … | Lade herunter |
|---|---|
| **eine NVIDIA-Grafikkarte** (GTX 10xx oder neuer) | `CLIPassoStudio-GPU-Setup.exe` **und** `CLIPassoStudio-GPU-Setup-1.bin` und `-2.bin` – alle drei in denselben Ordner, dann die `.exe` starten (GitHub erlaubt höchstens 2 GB je Datei) |
| **keine NVIDIA-Grafikkarte** | `CLIPassoStudio-CPU-Setup.exe` |
| **ohne Installation** (z. B. ein USB-Stick) | `CLIPassoStudio-CPU-Portable.zip` – entpacken, `CLIPassoStudio.exe` starten |
| **CLIPasso Studio schon installiert** | nichts – die App bietet {version} selbst an (*Einstellungen → Verhalten*; Betas mit „Auch Beta-Versionen anbieten“), auch vom Handy aus, und lädt nur die geänderten Dateien |

**Nur für die App, nicht herunterladen:** `…-Patch-from-…` (kleine Updates), `…-manifest.json` (die Dateiliste dazu), `SHA256SUMS-….txt` (Prüfsummen – die App prüft jeden Download damit; wer möchte, kann sie auch selbst vergleichen).

<details><summary>English</summary>

| You have … | Download |
|---|---|
| **an NVIDIA graphics card** (GTX 10xx or newer) | `CLIPassoStudio-GPU-Setup.exe` **and** `CLIPassoStudio-GPU-Setup-1.bin` and `-2.bin` – all three into one folder, then run the `.exe` (GitHub allows at most 2 GB per file) |
| **no NVIDIA graphics card** | `CLIPassoStudio-CPU-Setup.exe` |
| **no installation** (e.g. a USB stick) | `CLIPassoStudio-CPU-Portable.zip` – unpack, run `CLIPassoStudio.exe` |
| **CLIPasso Studio installed already** | nothing – the app offers {version} itself (*Settings → Behaviour*; betas with “Also offer beta versions”), also from the phone, and downloads only the changed files |

**For the app only, no need to download:** `…-Patch-from-…` (small updates), `…-manifest.json` (their file list), `SHA256SUMS-….txt` (checksums – the app checks every download against them; you can compare them yourself, too).

</details>
